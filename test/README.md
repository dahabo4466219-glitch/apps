# Test – Simple To‑Do List App

A minimal responsive web application that lets you add, delete, and mark tasks as complete. Tasks are saved in **localStorage**, so they survive page reloads and browser restarts.

## Features
- Add new tasks via the input field or pressing **Enter**.
- Click a task text to toggle its completed state.
- Delete a task with the ✕ button.
- Task count displayed in the footer.
- Fully responsive layout (desktop, tablet, mobile).
- Design follows the provided color palette, spacing, and typography.

## How to run
1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
2. No build step or server is required – it is a static site.

## Files
- `index.html` – markup and structure.
- `style.css` – all styling, using CSS variables for the design tokens.
- `script.js` – JavaScript handling state, UI updates, and persistence.
